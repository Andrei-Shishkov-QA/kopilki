# Для любой нейросети или разработчика

Прочитать по порядку:
1. **CLAUDE.md** — правила работы (главное: приложение всегда рабочее, журнал только дополняется).
2. **ARCHITECTURE.md** — как всё устроено.
3. **IDEAS.md** — все идеи и что делать дальше.

Проверка перед любой выкладкой: `npm test` и открыть страницу через `python -m http.server`.
