# Копилки Сергея

Семейная система «привычки и деньги»: фишки за дела, сделанные самостоятельно, карманные раз в неделю, четыре копилки (банк, цели, для других, кошелёк).

Сайт: https://andrei-shishkov-qa.github.io/kopilki/

## Как устроено

Приложение хранит только **журнал записей**. Всё остальное (копилки, банк, фишки, итоги недель) каждый раз пересчитывается из журнала. Исправление — это новая запись («отменить», «исправить»), старые записи не стираются.

```
index.html          страница
css/                стили (палитры, основа, экраны, версия 1.0)
src/engine/         движок: журнал → состояние (без браузера, тестируется в Node)
src/store/          хранилище журнала в Firebase Firestore (вход — семейный аккаунт)
vendor/firebase.js  библиотека Firebase 13.4.0, собранная в один файл
firestore.rules     правила доступа к базе (вставляются в консоль Firebase)
src/ui/             экраны и окна
tests/              тесты: npm test
```

Правило: **каждый файл — не длиннее 300 строк** (проверяется в `npm test`).

## Запуск у себя

Модули браузера не работают при открытии файла двойным щелчком, нужен любой локальный сервер:

```
python -m http.server 8000
```

и открыть http://localhost:8000

## Тесты

```
npm test
```

Каждый push в `main` запускает тесты и, если они зелёные, обновляет сайт (GitHub Actions → Pages).
