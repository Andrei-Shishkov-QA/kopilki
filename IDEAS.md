## Направления развития (стратегии)
| | Суть | Плюсы | Минусы | Статус |
|---|---|---|---|---|
| **A. Своя семья** | Приложение только для нас | Просто, бесплатно, без ответственности | Нет дохода | **Текущее** (до запуска C) |
| **B. Открытая копия** | Другие семьи копируют репозиторий и заводят свой Firebase | 0 работы и ответственности, бесплатно | Каждой семье ~40 мин настройки, обновления у них сами не приходят | Идея |
| **C. Сервис по подписке** | Одно приложение на много семей, оплата | Доход | Юр. часть, поддержка, данные чужих детей, ~350–550 тыс. токенов | **Цель на будущее (решение 27.11):** всё новое делается с прицелом на C |
Порядок, если выбираем C: каналы версий → много семей (сначала бесплатно 1–2 знакомые) → оплата → продажа. Подробно — kidbank/PLAN-SAAS.md в проекте Claude.
